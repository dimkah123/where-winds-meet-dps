# Gemini.md — Правила и инструкции для агента Gemini

## 1. Минимальное и точечное тестирование (Критическое правило)
- **НЕ запускать полный тестовый набор (`pnpm test` / `vitest run` без аргументов)**: в проекте сотни тяжелых симуляционных тестов, полный прогон длится несколько минут и тратит ресурсы.
- **Минимум тестов**: запускать **ТОЛЬКО** точечный тест на конкретный файл, который был изменен (например, `pnpm vitest run tests/engine/stepDistanceAndChargedReach.test.ts`).
- **Проверка типов**: перед коммитом и сдачей задачи запускать `pnpm run typecheck` (`tsc -b --noEmit`).
- **Новые тесты**: добавлять только минимально необходимые и быстрые проверки строго по измененному коду.

## 2. Стиль общения и формат ответов
- Общение с пользователем ведется строго на **русском языке**.
- Все ссылки на файлы обязательно оформляются кликабельными ссылками в формате markdown: `[filename.ext](file:///c:/path/to/filename.ext)` (для Windows пути с прямыми слэшами `/`).
- Ответы должны быть емкими, точными и понятными.

## 3. Специфика калькулятора Where Winds Meet (Stonesplit Strength)
- **Дальность и заряжки Мо (PhalanxCharged)**:
  - Первый солдат Мо (`anxisoldiermodown`) выпадает на расстоянии **3 метра** (+4% Flute bonus).
  - Второй солдат Мо (`anxisoldiermojump`) выпадает на расстоянии **5 метров** (+8% Flute bonus).
  - Сам удар заряжки приземляется на расстоянии **2 метров** (`displacement: { kind: "toTarget", meters: 2 }`, +3% Flute bonus).
  - Тики дудки (`Flute of the Tides`) во время каста скейлятся от текущей дистанции фазы заряда.
  - **Остальные умения**: берут дальность каста строго из своих **стоковых значений** (без искусственного завышения reach или displacement).
- **Ротации**:
  - `Mixed Dummy 1 Min` — основная встроенная ротация в категории `Mo - Rotation`.
  - `3 Heng Charge` — в категории `Mo - Rotation`.
  - Ротации для Хэн — в категории `Heng - Rotation`.
